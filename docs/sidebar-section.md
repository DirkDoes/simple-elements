# Sidebar section

```html
<se-sidebar-section title="Workspace" collapsible>
  <se-sidebar-button label="Dashboard" icon="dashboard"></se-sidebar-button>
</se-sidebar-section>
```

Attributes: `title`, `collapsible`, and `collapsed`. Collapsible sections animate open and closed. The title remains useful as a chapter label when the same section is composed into another navigation pattern.
