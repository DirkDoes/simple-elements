# Date picker

```html
<se-date-picker label="Start date" name="event[start_date]" value="2026-09-06" min="2026-01-01" required></se-date-picker>
```

Uses a native `input[type="date"]`, so it submits normally in HTML and Ruby on Rails forms. Supports `name`, `value`, `min`, `max`, `step`, `required`, and `disabled`.
