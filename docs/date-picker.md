# Date picker

```html
<se-date-picker label="Start date" name="event[start_date]" value="2026-09-06" min="2026-01-01" required></se-date-picker>
```

Opens the Simple Elements calendar popover and submits a hidden `YYYY-MM-DD` value normally in HTML and Ruby on Rails forms. Supports `name`, `value`, `min`, `max`, `required`, `disabled`, `placeholder`, and an optional BCP 47 `locale` such as `nl-NL`.
