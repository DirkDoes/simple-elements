# Workspaces

Browse **Patterns → Workspaces** in the showcase for a workspace directory and its child project cards. Compose `se-workspace-card` entries above a responsive grid of `se-project-card` elements. Workspace membership and project counts are display metadata supplied by the application.

The project-card preview includes standalone pagination beneath the grid. It demonstrates page selection without fetching data or changing the displayed cards. See [Pagination](pagination.md) to connect it to application data.
