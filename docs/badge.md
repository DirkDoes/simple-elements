# Badge

```html
<se-badge tone="success" text="Active"></se-badge>
<se-badge tone="warning" icon="alert" text="Needs attention"></se-badge>
<se-badge tone="error" icon="x" aria-label="Error"></se-badge>
```

Tones: `gray`, `brand`, `success`, `warning`, `error`, `info`, and `important`. Set `text`, `icon`, or both. Add `aria-label` to icon-only badges.
