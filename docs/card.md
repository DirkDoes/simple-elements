# Card

```html
<se-card>
  <se-title level="card">Usage</se-title>
  <se-text>Any HTML can go inside.</se-text>
</se-card>
```

Use `variant="white"` (default), `variant="gray"`, or `variant="transparent"` to choose the surface treatment.

Set `color` to any valid CSS color for a custom background. A valid `color` overrides `variant`.

Cards provide the shared surface, border, radius, spacing, and shadow.
