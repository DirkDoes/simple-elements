# List

```html
<se-list>
  <se-list-header>Recent activity</se-list-header>
  <se-list-row><se-icon name="user"></se-icon><span>A user joined</span></se-list-row>
  <se-list-row><se-icon name="file"></se-icon><span>A file was uploaded</span></se-list-row>
</se-list>
```

A list keeps row contents deliberately flexible. Use a table when every row must follow the same columns.
