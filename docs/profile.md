# Profile

```html
<se-profile name="Sarah Jenkins" subtitle="Lead Designer" initials="SJ" tone="brand" clickable></se-profile>
```

Use `tone` for the avatar color (`gray`, `brand`, `success`, `warning`, `error`, `info`, or `important`). Add `compact` to show only the avatar; the same presentation is applied automatically inside a collapsed sidebar.

Inside a collapsed `se-sidebar`, the profile automatically reduces to its avatar.

Attributes: `tone`, `name`, `subtitle`, `initials`, `clickable`, and `compact`.
