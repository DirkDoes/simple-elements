# Input

```html
<se-input label="Email" name="email" type="email" icon="mail" required></se-input>
<se-input label="Biography" name="bio" type="textarea" hint="Keep it short."></se-input>
<se-input label="Username" error="Already taken."></se-input>
```

Supports native input types plus `type="textarea"`. Attributes: `label`, `name`, `type`, `value`, `placeholder`, `icon`, `hint`, `error`, `required`, `disabled`, and `fixed` for a non-resizable textarea. Read or set the element's `value` property.
