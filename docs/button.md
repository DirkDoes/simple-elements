# Button

```html
<se-button variant="brand"><se-icon name="send"></se-icon>Publish</se-button>
<se-button variant="danger">Delete</se-button>
<se-button icon-only aria-label="Settings"><se-icon name="settings"></se-icon></se-button>
```

`variant` accepts `primary`, `brand`, `secondary`, `ghost`, `danger`, or `label`. Native `type`, `disabled`, and click events are supported.
