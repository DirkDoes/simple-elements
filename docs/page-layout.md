# Page layout pattern

Page layouts compose `se-sidebar`, its regions and navigation components, plus an optional `se-topbar`. The shared `layout-mode` attribute defaults to `always` and accepts `mobile-only` and `desktop-only` on layout elements and regions. A sidebar additionally accepts `responsive`, turning the same navigation into a top-down mobile overlay. Add `overlay` when an expanded desktop sidebar should float above the page; its collapsed rail returns to the layout after the width transition. Omitting `layout-mode` behaves like `always`. Desktop layouts without a top bar can use `layout-mode="mobile-only"` on one containing the sidebar toggle and essential compact actions. Give duplicated sidebar content such as its brand header or profile footer `layout-mode="desktop-only"` when the mobile equivalent lives in that top bar. No application CSS is required. See the live [Page Layout examples](https://dirkdoes.github.io/simple-elements/examples/#page-layout) and use the shared viewport selector to compare desktop, tablet, and phone layouts.
