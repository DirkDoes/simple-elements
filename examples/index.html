 Attributes AttributeDescriptionDefaultOverride typeSets the native input type, or renders a textarea. nameNames the native field for HTML and Rails form submission. valueSets the field's initial value. placeholderShows a type-aware hint while the field is empty. labelAdds an accessible label above the field. iconOverrides the type-aware icon where one is provided. hintAdds supporting text below the field. errorShows an error state and replaces the hint. disabledPrevents interaction with the native field. requiredMarks the field as required for form validation. fixedDisables resizing when the type is textarea.
